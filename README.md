Clinic Room Status Display Application
Overview

This application is designed to streamline room management in a clinic. Doctors can easily update the status of rooms from their iPads, with customizable statuses such as "Occupied," "Free," or any other status defined by the clinic. Receptionists can view these updates in real-time on a dedicated iPad at the reception desk, making it easy to manage room assignments and doctor availability efficiently.

Key Features

Customizable Statuses: Create and manage a variety of room statuses (e.g., Occupied, Free, or custom statuses) with customizable colors.

Real-Time Updates: Any change in room status is reflected instantly on the reception iPad.

Easy Status Creation: The app includes a page for creating new statuses, allowing for dynamic and flexible room management.

Visual Management: Different statuses are represented by distinct colors for quick and easy identification.

Technologies Used

Frontend: Quasar Framework, Vue.js

Backend: MongoDB (for data storage)

Hosting/Server: Render (for hosting and handling API requests)

Purpose

This application enhances clinic operations by providing real-time, flexible room status updates, reducing waiting time, and improving overall room assignment management.
